# RAG over research papers

Ask questions about 3 AI research papers (Attention Is All You Need, BERT, RAG). The tool finds the most relevant passages with page numbers.

## Tools
LangChain, FAISS, Hugging Face sentence-transformers (all-MiniLM-L6-v2), PyPDFLoader

## Results
Score: 6/10 questions returned the right passage in the top 3 (chunk size 1000).

## How to run
Open the notebook in Google Colab, upload the 3 PDFs, run all cells.
